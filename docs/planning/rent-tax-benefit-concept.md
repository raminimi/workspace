# [기획안] 월세 자동이체 연계 '원스탑 월세 세제혜택 케어'

> 출처: Gemini 검색/기획 초안 (외부 리서치 결과를 그대로 아카이빙). 핀테크/뱅킹 서비스 기획 관점에서 '월세 자동이체 신청 시점'을 트리거로 삼아, 고객의 복잡한 증빙 및 국세청 신청 허들을 스크래핑과 자동화 로직으로 해결하는 서비스 플로우 및 화면 프로토타입(UX/UI 기획서).

## 1. 서비스 컨셉 및 비즈니스 로직

### (1) 핵심 전략: 세액공제 vs 소득공제 지능형 분기 (Decision Engine)

* **Rule A (세액공제 최우선):** 총급여 8,000만 원 이하 + 무주택 + 주택 요건 충족 시, 최대 170만 원 세액공제(15~17%)가 현금영수증(30% 소득공제)보다 압도적으로 유리하므로 세액공제 트랙으로 유도.
* **Rule B (현금영수증 대체):** 소득 초과자(8,000만 원 초과), 유주택자, 주택 기준시가 초과 등 세액공제 불가 대상은 **국세청 '주택임차료 현금영수증 발급 신청' 자동 대행**으로 분기하여 30% 소득공제 혜택 확보.

```
[월세 자동이체 설정]
        ↓
[마이데이터/공공 스크래핑 원클릭 조회]
 ├── 소득: 전년도 근로소득원천징수/소득금액증명원
 ├── 주택: 주민등록표등본(무주택 세대주/원), 부동산공시가격(기준시가 4억/85㎡)
 └── 전입: 등본 상 주소 == 자동이체 기재 임차 주소
        ↓
 [적격성 판정 엔진]
 ├── [조건 충족] ──> "월세 세액공제 관리 팩" 생성 (연말정산 원클릭 패키지)
 └── [조건 미충족] ─> 국세청 홈택스 "주택임차료 현금영수증" 자동 등록 대행
```

### (2) 스크래핑 및 연계 데이터 소스

1. **정부24 스크래핑:** 주민등록표등본 (무주택 여부, 세대주/세대원 확인, 현주소지 확인)
2. **국세청 홈택스 스크래핑:** 소득금액증명 / 근로소득 원천징수영수증 (총급여 5,500만 / 8,000만 원 구간 확인)
3. **부동산원 / 국토교통부 연계:** 주택 기준시가 및 전용면적 자동 조회 (공시가격 4억 원 or 85㎡ 이하)
4. **국세청 홈택스 민원 신청 스크래핑:** 주택임차료 현금영수증 발급 신청 대행 (현금영수증 분기 시)

* **UX 포인트:** 집주인 눈치를 보는 임차인을 위해 "집주인 동의 불필요" 문구 전면 배치.

│ │ 💡 잠깐! 매월 내는 월세,            │ │

├────────────────────────────────────────┘

## 3. 고객 관점의 페인포인트 해소 전략

| 고객의 불편/두려움 (Pain Point) | 서비스 구현 해결책 (Solution Feature) |
| --- | --- |
| **"집주인한테 알림이 가서 사이가 틀어질까 두려움"** | • UI 내 **'안심 안내'** 반복 노출: "세법상 임차인의 정당한 권리이며, 홈택스 신청 및 세액공제 시 임대인에게 별도 통보가 가지 않습니다."<br><br>• 불안해하는 사용자를 위해 **'퇴거 후 5년 이내 경정청구 예약(이사 후 환급받기)'** 옵션 제공. |
| **"매달 이체확인증 다운받아 모으기 번거로움"** | • 은행 자체 자동이체 원장과 연동하여, 매월 이체 성공 시점에 **'공제 증빙 데이터베이스'에 이체확인증 PDF를 자동 아카이빙**. |
| **"내가 세액공제 대상인지 소득공제 대상인지 모름"** | • 스크래핑 엔진이 총급여와 주택 요건을 대조하여 **환급액이 더 큰 쪽(세액공제 17% vs 현금영수증 30%)으로 자동 배정**. |
| **"이사 가서 주소지가 바뀌었을 때의 누락"** | • 공공마이데이터(행안부 주소변경 알림 서비스)와 연동하여, **전입신고 변경 감지 시 계약서 재등록 알림 푸시** 발송. |

## 4. 제휴 및 기능 확장 제언 (Roadmap)

1. **국세청 홈택스 간편인증 API 제휴 (정부 주도 연계):**
   * 현금영수증 발급 신청은 현재 홈택스 웹 스크래핑 방식으로 구현 가능하지만, 국세청 오픈API/공공 마이데이터 사업과 제휴하여 공인된 전자문서 형태로 다이렉트 전송 체계 구축.

2. **청약가점 및 무주택 증빙 락인(Lock-in):**
   * 본 프로세스에서 수집된 '무주택 세대주 인증' 데이터를 바탕으로, 앱 내 주택청약 관리 및 전월세 대출 상품 추천으로 크로스셀링(Cross-selling) 연계.
